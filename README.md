# Чёрный список для GameDev.ru

Расширение для Firefox, Chrome и Brave, которое помогает скрывать темы и сообщения выбранных пользователей на форуме [GameDev.ru](https://gamedev.ru/).

## Возможности

- Добавление пользователя в чёрный список прямо со страницы темы кнопкой **«в ЧС»**.
- Отдельные настройки для тем и постов каждого пользователя:
  - **показывать** — ничего не менять;
  - **скрывать** — полностью убрать со страницы;
  - **заменять** — показать нейтральную заглушку без имени и аватара.
- Заглушку поста можно нажать, чтобы временно увидеть его текст.
- К каждому пользователю можно добавить заметку — например, за что он попал в чёрный список. Заметку видите только вы: она редактируется в окне расширения и показывается во всплывающей подсказке у заглушки поста и у кнопки **«из ЧС»**.
- При желании расширение может автоматически удалять сообщения выбранного пользователя из ваших тем — только там, где это разрешает сам форум.

Чёрный список и заметки сохраняются в профиле браузера и синхронизируется между вашими устройствами, если включена синхронизация расширений в браузере.

## Установка

1. Скачайте проект и распакуйте архив в отдельную папку.
2. Откройте страницу расширений:
   - `brave://extensions` в Brave;
   - `chrome://extensions` в Chrome.
3. В Chrome или Brave включите **Режим разработчика**, нажмите **Загрузить распакованное расширение** и выберите папку проекта.

### Firefox

Для проверки без установки откройте `about:debugging#/runtime/this-firefox`, нажмите **Загрузить временное дополнение** и выберите `manifest.json`. Такое дополнение действует до перезапуска Firefox.

Для постоянной установки Firefox требует подписанный файл `.xpi`. Для распространения дополнение нужно подписать через addons.mozilla.org.

Собрать файл для Firefox локально можно командой `./build-firefox.ps1`. Готовый `.xpi` появится в папке `dist`. Локальная сборка не подписана Mozilla.

Для сборки и подписи одной командой скопируйте `.web-ext-credentials.example.json` в `.web-ext-credentials.json`, заполните API-ключи AMO и запустите `./release-firefox.ps1`. Скрипт использует `web-ext`, отправляет чистую сборку в Mozilla и сохраняет подписанный `.xpi` в `dist`. Файл с ключами исключён из Git и из пакета расширения.

После установки откройте GameDev.ru. Пользователей можно добавлять кнопкой **«в ЧС»** рядом с их сообщениями или через значок расширения на панели браузера.

## Обновление настроек

После изменения чёрного списка открытые вкладки GameDev.ru перезагружаются автоматически, чтобы новые настройки сразу вступили в силу.
